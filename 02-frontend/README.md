## Overview

This week you go from “how does a website work?” to shipping your own personal site with a modern stack: **Next.js**, **React**, **TypeScript**, and **Tailwind CSS**. By the end of homework, you’ll have a multi-page site about you — and a second page for something you love.

## Agenda

   - Confirm Node.js / npm works

   - Scaffold a Next.js + Tailwind project
   - Quick tour of the files that appear (`page.tsx`, `layout.tsx`, etc.)

   - Style it with Tailwind

3. **Wrap-up (~5 min)**
   - Homework: polish + nav + interest page
   - Optional later: Vercel

## What you should know coming in

- How browsers, HTML, CSS, and JavaScript fit together

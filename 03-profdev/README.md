# Lesson 3: Professional Development

**Date:** Feb 23rd, 2026

> Come with a revised resume (**3 printed copies**), a co-op path in mind, and the [pre](pre/README.md) done. Class is mostly a live walkthrough — not a lecture on STAR or careers from scratch.

## Overview

Resume, career paths, behavioral storytelling (STAR), and a classic interview coding problem (Two Sum). Homework adds an elevator pitch, one STAR writeup, and a slightly harder LeetCode.

## Agenda

1. **Check-in (~5–10 min)** — resumes + questions from pre
2. **Activity: Two Sum (~60–70 min)** — read the problem, try ideas, then class walkthrough
3. **Wrap-up (~5–10 min)** — homework + optional peer resume swap

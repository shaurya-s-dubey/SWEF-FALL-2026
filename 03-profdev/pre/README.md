# Pre-work: Professional Development

Class time is a walkthrough + discussion — not a lecture covering this from scratch. Budget ~**1 hour** (plus printing).

---

## What you should have ready

- A provisional idea of which **co-op / role path** you want
- Know what **STAR** is
- Updated resume + **3 printed copies** in your bag

---

## 1. Career paths (~20–25 min)

Skim enough to compare roles. Specific > “I want tech.”

| Path | Rough idea | Watch / read (pick what you need) |
| --- | --- | --- |
| Software Engineer | Build products: features, bugs, reviews, deploys | [Day in the life (2024)](https://www.youtube.com/watch?v=tjADR5bJDeQ) |
| Product Manager | Owns *what* / *why*; less day-to-day coding | [PM 101 (short)](https://www.youtube.com/watch?v=xe60PeiscYo) · [Atlassian overview](https://www.atlassian.com/agile/product-management/product-manager) |
| Data Engineer | Pipelines, warehouses, reliable data | [How data engineering works](https://www.youtube.com/watch?v=qWru-b6m030) |
| Data Scientist | Analysis, models, insights | [What is data science?](https://www.youtube.com/watch?v=xC-c7E5PK0Y) |
| UX / Design | Research + usable interfaces | [What is UX?](https://www.youtube.com/watch?v=SRec90j6lTY) (skim) |
| DevOps / SRE | Infra, deploy, reliability | [CI/CD in 100 seconds](https://www.youtube.com/watch?v=scEDHsr3APg) |

Before class, decide: **which path are you most curious about for a co-op, and why (one sentence)?**

---

## 2. STAR (~15–20 min)

Behavioral interviews want a real situation with a clear outcome — not your life story.

Watch: [STAR Interview Method Explained](https://www.youtube.com/watch?v=dWK26jZgsM8)

Read: [The Muse — STAR Method](https://www.themuse.com/advice/star-interview-method)

| | Meaning |
| --- | --- |
| **S**ituation | Context (short) |
| **T**ask | What *you* needed to do |
| **A**ction | Specific steps you took (“I”, not only “we”) |
| **R**esult | Outcome + what you learned |

---

## 3. Resume + print (~25–35 min)

Update your resume, then print **3 copies**.

- One page; clear contact + LinkedIn / GitHub if you have them
- Education, SWEF / projects, experience with **verb-led** bullets
- Near the top, make the co-op target obvious (e.g. “Seeking a software engineering co-op…”) — provisional is fine

Use your school / co-op resume guide if you have one.
